# Scientific framework

DarkDNA-Observer identifies unusual noncoding genomic architectures and generates falsifiable candidate hypotheses. It does not infer selected function from activity, complexity, conservation, compression, predicted shape, motif presence, or structural propensity.

The required reasoning order is:

```text
observed feature
-> anomaly relative to an explicit null
-> candidate mechanistic bridge
-> causal experiment
-> organism-fitness and evolutionary interpretation
```

## Separate evidence questions

The framework keeps these questions separate:

1. Is the exact sequence architecture unusual?
2. Is a physical conformation possible, context-conditioned, or observed?
3. Is transcription itself causal, is an RNA product causal, or is the signal transcriptional noise?
4. Is an effect sequence-specific, quantity-dependent, or mixed?
5. Does endogenous perturbation alter a molecular/cellular phenotype?
6. Does that effect alter organism-level fitness?
7. Is the element currently maintained by selection?
8. Was its origin adaptive, neutral, selfish, deleterious, or unresolved?
9. Was it exapted or domesticated after origin?

No universal functional score is permitted.

## Phase 1 contracts

- Multiscale sequence texture is reported only when scale-range, finite-size, fit, surrogate, multiple-mapping, and nearby-window diagnostics are available. The screen is not a fractal label.
- Compression is a statistical-structure measure. Ratios are header-corrected and calibrated against same-length sequence nulls.
- DNA shape uses validated predictor records when available. Missing predictors return `status=unavailable`, `value=NA`, and a reason.
- Non-B output distinguishes Level 1 sequence potential, Level 2 context-conditioned formation, and Level 3 observed structure. Phase 1 sequence input supplies Level 1 only.
- Primitive views use audited orientations, robust cohort standardization, a correlation audit, and covariance-aware combination. They remain screening scores, not probabilities or p-values.
- Empirical p-values require a named null distribution. Genomic rank is not a null.
- Residual calibration prefers blocked cross-fitting, conditional variance, held-out quantile residuals, conformal intervals, block bootstrap, and heteroscedasticity diagnostics.
- Unexplained anomaly is held-out multivariate outlierness. It is unavailable when independent block groups or enough informative axes are absent.
- Negative evidence can reject or downgrade candidates. Missing evidence never counts as positive support.

## Static sequence limits

Static sequence can motivate, but cannot confirm, memory, hysteresis, pulse decoding, criticality, future-state bias, noise insulation, chromatin motion, trajectory gating, non-B formation, charge transfer, or quantum effects. Dynamic and physical claims require the corresponding time, perturbation, context, replication, and direct observation data.

## Allowed Phase 1 claim

DarkDNA-Observer Phase 1 ranks sequence-specific architecture screens under explicit calibration and availability rules, retains negative conclusions, and generates testable bridge hypotheses. A high value is not evidence of biological function, selected maintenance, adaptive origin, or design.
