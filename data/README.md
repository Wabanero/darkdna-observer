# DarkDNA-Observer Test Data

This directory is for small, reproducible test data only.

## Level A: Toy Data

`data/toy/` contains deterministic synthetic data generated by:

```bash
python scripts/make_toy_data.py --out data/toy --seed 42
```

Toy data is small enough to commit and is used by normal unit and integration tests.

## Level B: Yeast R64 Chromosome I

`data/reference/yeast_R64_chrI/` is an optional small real-genome technical integration fixture for *Saccharomyces cerevisiae* S288C/R64 chromosome I.

Normal pytest skips this dataset if files are absent. Prepare it with local source files:

```bash
python scripts/prepare_test_references.py \
  --dataset yeast_R64_chrI \
  --no-download \
  --source-dir /path/to/local/yeast_reference \
  --out data/reference/yeast_R64_chrI
```

## Level C: Arabidopsis TAIR10 Chr1 2Mb

`data/reference/arabidopsis_TAIR10_chr1_2Mb/` is an optional plant/non-model integration fixture for chromosome 1 positions 1-2,000,000.

Normal pytest skips this dataset if files are absent. Prepare it with local source files:

```bash
python scripts/prepare_test_references.py \
  --dataset arabidopsis_TAIR10_chr1_2Mb \
  --no-download \
  --source-dir /path/to/local/arabidopsis_reference \
  --out data/reference/arabidopsis_TAIR10_chr1_2Mb
```

Download tests are optional and marked `download`. Full genomes should not be committed to this repository.

Prompt 1 candidate-only interpretation remains enforced for all datasets. Static sequence data may emit `*_candidate` labels but must not emit confirmed dynamic, teleological, active-inference, or future-state primitive labels.
