# DarkDNA-Observer Test Data

This directory contains small, reproducible datasets that are committed so the
analysis pipeline can run immediately after checkout.

## Toy Data

`data/toy/` contains deterministic synthetic data generated by:

```bash
python scripts/make_toy_data.py --out data/toy --seed 42
```

The candidate intervals are artificial signatures for tests and demos. They are
not biological claims.

## Yeast R64 Chromosome I

`data/reference/yeast_R64_chrI/` contains a small real-genome technical fixture
for *Saccharomyces cerevisiae* S288C/R64 chromosome I.

Regenerate it from Ensembl Genomes with:

```bash
python scripts/prepare_test_references.py \
  --dataset yeast_R64_chrI \
  --download \
  --force \
  --out data/reference/yeast_R64_chrI
```

## Arabidopsis TAIR10 Chr1 1-2 Mb

`data/reference/arabidopsis_TAIR10_chr1_2Mb/` contains a small plant/non-model
fixture for chromosome 1 positions 1-2,000,000.

Regenerate it from Ensembl Genomes with:

```bash
python scripts/prepare_test_references.py \
  --dataset arabidopsis_TAIR10_chr1_2Mb \
  --download \
  --force \
  --out data/reference/arabidopsis_TAIR10_chr1_2Mb
```

The repository stores only compact subsets and metadata. Temporary full-source
downloads are ignored.

Sequence-first candidate-only interpretation remains enforced for all datasets.
Static sequence data may emit `*_candidate` labels, but it must not emit
confirmed dynamic or functional claims.
